# Generative AI Research

## Project overview

This repository supports the research project **Using Generative AI Tools - Boon or Bane**. It contains literature, survey data, analysis scripts, interview materials, research drafts, final reports, and supporting images.

## Repository structure

- `01_Literature_Review/`: books and journal articles used in the literature review.
- `02_Quantitative_Analysis/`: survey questions, raw data, Python analysis scripts, and results.
- `03_Qualitative_Analysis/`: anonymised interview transcripts and qualitative research materials.
- `04_Drafts_and_Reports/`: research proposals, draft documents, submitted papers, and final reports.
- `05_Additional_Materials/`: images and other supporting materials.

## How to navigate the files

The numbered folders follow the main stages of the research process. Original survey data are stored separately from analysis scripts and results. Draft documents and final reports are also kept in different locations to reduce version confusion.

## File naming convention

Files use descriptive names, underscores, participant numbers, and version numbers. Examples include:

- `Survey_Data_Raw.csv`
- `Participant_01_Transcript.docx`
- `Generative_AI_Final_Report_v01.docx`

This naming convention makes files easier to identify, sort, retrieve, and compare.

## Collaboration guidelines

1. Fetch and pull the latest version before starting work.
2. Create a clearly named branch for each task.
3. Make changes only in the appropriate project folder.
4. Write a meaningful commit message describing the change.
5. Submit a pull request for review before merging into `main`.
6. Resolve merge conflicts carefully and confirm the final content.

## Data access and privacy

Interview transcripts, consent forms, and identifiable survey data may require restricted access. Sensitive research data should be anonymised and stored in an approved private location before sharing. Public versions of the project must not contain confidential participant information.
